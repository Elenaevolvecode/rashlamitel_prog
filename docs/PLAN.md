# План доведения Расхламителя

**Цель:** довести программу до рабочей версии, которую не стыдно показать в портфолио и дать людям.
Монетизации нет. Позиционирование: *«CCleaner для людей: одна кнопка, человеческий язык, ничего не ломает»*.
Просто по умолчанию, подробности по запросу.

## Принципы

- **Ничего важного не трону.** Свои файлы пользователя только в Корзину. Корзину чистим только с подтверждения.
  Пароли, закладки, входы на сайты не трогаем никогда.
- **Честные цифры.** Показываем, сколько реально удалилось, а не сколько нашлось при сканировании.
- **Простой язык.** Каждый пункт объясняется: что это, почему можно удалить, что изменится после.
- **Не висим в фоне** и не добавляем себя в автозагрузку. Напоминания идут через Планировщик заданий Windows.
- Каждый этап заканчивается рабочей версией, которую можно поставить.

## Этапы

### Этап 1. Фундамент ✅ (0.9.0–0.9.3, проверено на Windows 10 Pro и в Песочнице)
- [x] Режим проверки: показывает, что удалил бы, но ничего не удаляет (включён по умолчанию)
- [x] Сканирование и удаление на Node вместо PowerShell: быстрее и честно считает освобождённое место
- [x] Без двойного счёта (Temp\Low внутри Temp), свежие временные файлы (моложе суток) не трогаем
- [x] Корзина только с подтверждением; старые установщики из «Загрузок» в Корзину, а не насовсем
- [x] Открытый браузер: спрашиваем, закрыть или пропустить
- [x] Настройки сохраняются (онбординг один раз, история очисток), онбординг не мелькает
- [x] Безопасный запуск PowerShell: имена программ не могут сломать или подменить команду
- [x] Автозагрузка: правильные разделы реестра (Run32, папка «Автозагрузка»), имена ярлыков из самой папки,
      проверка, что изменение применилось; совпадает с Диспетчером задач
- [x] Программы: интерфейс передаёт только номер программы; Расхламитель не показывает сам себя
- [x] Окно подстраивается под экран ноутбука; шрифт внутри программы; читаемый серый текст
- [x] Убраны донат, выбор языка и отдельный сайт; «О программе» с рабочими ссылками
- [x] Автотесты + сборка .exe в GitHub Actions на Windows; ярлык на рабочем столе при каждом обновлении

### Этап 3. Напоминания об очистке ← сейчас (0.12–0.13)
- [x] Задание «Rashlamitel Reminder» в Планировщике Windows (без прав администратора) запускает Расхламитель с ключом --remind без окна

      («Посмотреть» / «Не сейчас» / «Больше не напоминать»), «Посмотреть» открывает экран «Вот что я нашёл».

- [x] Срок отсчитывается от последнего запуска программы (задание пересоздаётся при каждом запуске)
- [x] Настройки: «Напоминать о чистке» (по умолчанию включено, раз в месяц), частота: неделя / две недели / месяц;
      «Показать, как выглядит напоминание» — для проверки
- [x] Удаление программы убирает и задание из Планировщика (при обновлении — нет)
- [x] Автотест на Windows в GitHub Actions по-настоящему создаёт, меняет и удаляет задание
- [ ] Проверить на компьютере: окошко, «Посмотреть» → экран предпросмотра, «Больше не напоминать», запуск из Планировщика
