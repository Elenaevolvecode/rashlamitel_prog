# Как тестировать, не рискуя своим компьютером

## Где взять установщик

1. Открыть репозиторий на GitHub → вкладка **Actions**.
2. Выбрать последний зелёный запуск «Тесты и сборка Windows» (зелёная галочка).
3. Внизу страницы, в разделе **Artifacts**, скачать **Rashlamitel-Setup**. Это zip, внутри `Rashlamitel-Setup-<версия>.exe`.

Иногда Windows показывает «Windows защитил ваш компьютер», потому что у программы нет подписи.
Тогда нажмите **Подробнее → Выполнить в любом случае**. Если распаковывать zip через WinRAR,
предупреждения обычно не бывает: WinRAR не переносит на файл отметку «скачано из интернета».

---

## Уровень 1. На своём компьютере, только режим проверки

Сразу после установки включён **режим проверки**: программа показывает, что удалила бы, но ничего не трогает.
Пока вверху главного экрана видна **бирюзовая плашка** «Режим проверки», удаления не будет.

Здесь же, на своём компьютере, можно спокойно проверять вкладку **«При включении»**.
Отключение там обратимо: программа ставит отметку «отключено», как Диспетчер задач, и её можно снять обратно.

## Уровень 2. Песочница Windows, для настоящей очистки

**Что это.** Песочница — одноразовая чистая Windows, которая открывается в окне внутри вашей.
Ваши файлы она не видит. Закрыли окно, и всё, что в ней было, исчезло навсегда.
Поэтому в ней можно смело выключать режим проверки и чистить по-настоящему.

### Шаг 1. Проверить, что компьютер это умеет (один раз)

1. Нажать **Ctrl + Shift + Esc**, откроется Диспетчер задач. Если он маленький, нажать «Подробнее».
2. Вкладка **Производительность** → слева **ЦП**.
3. Справа внизу найти строку **«Виртуализация»**:
   - **Включено** — всё хорошо, переходите к шагу 2;
   - **Отключено** — её нужно включить в BIOS. Напишите мне модель ноутбука, подскажу, где это.

### Шаг 2. Включить Песочницу (один раз)

1. Нажать **Win + R**, ввести `optionalfeatures` и нажать **Enter**.
   Откроется окно «Компоненты Windows».
2. Пролистать вниз и найти **«Песочница Windows»** (может называться **Windows Sandbox**).
3. Поставить галочку → **ОК**. Windows немного подумает.
4. Когда попросит, **перезагрузить** компьютер.

### Шаг 3. Запустить Песочницу (каждый раз)

1. **Пуск** → начать печатать «Песочница» или «Windows Sandbox» → запустить.
2. Через полминуты–минуту откроется окно с чистым рабочим столом Windows. Это и есть Песочница.

### Шаг 4. Перенести туда установщик

1. В **своей** Windows найти `Rashlamitel-Setup-….exe` (обычно в «Загрузках»).
2. Правой кнопкой → **Копировать** (или Ctrl + C).
3. Щёлкнуть по рабочему столу **внутри окна Песочницы** → правой кнопкой → **Вставить** (или Ctrl + V).
4. Дважды щёлкнуть по файлу в Песочнице, программа установится и запустится.

### Шаг 5. Насоздавать мусора

В Песочнице Windows свежая, мусора почти нет, поэтому немного намусорим:
1. Открыть **Edge** внутри Песочницы, зайти на 10–15 сайтов: новости, YouTube (включить пару видео), маркетплейсы.
   Так наберётся кэш браузера.
2. Создать на рабочем столе пару файлов (правой кнопкой → Создать → Текстовый документ) и удалить их, чтобы что-то было в Корзине.
3. Закрыть Edge (или оставить открытым, чтобы проверить вопрос «Браузер открыт»).

### Шаг 6. Почистить по-настоящему

1. Посмотреть свободное место **прямо перед** нажатием «Удалить отмеченное» (а не в начале — Windows в Песочнице сама много пишет на диск в фоне, и сравнение «до» за десять минут до очистки ничего не покажет): **Проводник → Этот компьютер**, под диском C написано «свободно … ГБ». Запомнить.
2. В Расхламителе: **⚙** справа вверху → выключить **«Режим проверки»** → **← Назад**.
   Бирюзовая плашка должна пропасть.
3. Нажать **«Посмотреть, что нашлось»**, отметить нужное (например, поставить галочку на Корзине) → **«Удалить отмеченное»**, ответить на вопрос про открытые программы.
4. После итога снова посмотреть свободное место на диске C. Оно должно вырасти примерно на столько, сколько написала программа.

### Шаг 7. Закрыть Песочницу

Закрыть окно Песочницы крестиком → подтвердить. Всё внутри удалится.
В следующий раз Песочница снова будет чистой, и установщик придётся скопировать заново.

## Что проверить в этой версии (0.12.0) — напоминания

Можно на своём компьютере, это безопасно: напоминание ничего не удаляет.

- [ ] ⚙ Настройки: есть «Напоминать о чистке» (включено) и «Как часто: Раз в месяц»
- [ ] «Показать, как выглядит напоминание» → через несколько секунд в правом нижнем углу уведомление Windows от «Расхламитель ПК»
- [ ] Нажать на уведомление → открывается экран «Вот что я нашёл»
- [ ] Задание в Планировщике: Пуск → «Планировщик заданий» → «Библиотека планировщика заданий» → есть **Rashlamitel Reminder**,
      в «Триггерах» — повтор раз в 30 дней, первый запуск через месяц от сегодня
- [ ] Сменить частоту на «Раз в неделю» → в Планировщике (нажать «Обновить») повтор раз в 7 дней
- [ ] Выключить напоминания → задание из Планировщика пропало; включить → снова появилось
- [ ] **Проверка «как по-настоящему»:** в Планировщике правой кнопкой по Rashlamitel Reminder → «Выполнить».
      Окно программы не открывается. Если мусора больше 1 ГБ — приходит уведомление, если меньше — ничего не происходит
      (программа тихо закрылась)
- [ ] Удалить Расхламитель (Параметры → Приложения) → задание из Планировщика тоже пропало. Потом поставить обратно

Если уведомление не появляется: Параметры → Система → Уведомления и действия — уведомления должны быть включены,
а режим «Не беспокоить» («Фокусировка внимания») выключен.

Найденные проблемы просто пишите мне словами, лучше со скриншотом (можно в папку `scrin`).
