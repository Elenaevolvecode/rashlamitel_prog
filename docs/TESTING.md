# Как тестировать, не рискуя своим компьютером

## Где взять установщик

1. Открыть репозиторий на GitHub → вкладка **Actions**.
2. Выбрать последний зелёный запуск «Тесты и сборка Windows».
3. Внизу страницы, в разделе **Artifacts**, скачать **Rashlamitel-Setup** (это zip, внутри .exe).

При запуске Windows покажет «Windows защитил ваш компьютер». Это из-за отсутствия подписи:
**Подробнее → Выполнить в любом случае**.

## Уровень 1. На своём компьютере — только режим проверки

Сразу после установки включён **режим проверки**: программа показывает, что удалила бы, но ничего не трогает.
Вверху главного экрана в этом режиме видна бирюзовая плашка. Пока она есть, удаления не будет.

## Уровень 2. Песочница Windows — для настоящей очистки

Песочница — одноразовая чистая Windows внутри вашей. Закрыли окно, и всё исчезло. Ваши файлы она не видит.

**Включить один раз:**
1. Пуск → набрать «Включение или отключение компонентов Windows».
2. Поставить галочку **«Песочница Windows»** (Windows Sandbox) → ОК → перезагрузить компьютер.
   Если пункт серый, нужно включить виртуализацию в BIOS. Напишите мне, разберёмся.

**Каждый раз:**
1. Пуск → **Windows Sandbox**.
2. Скопировать установщик (Ctrl+C у себя → Ctrl+V в окне песочницы) и установить.
3. Насоздавать мусора: открыть Edge, походить по сайтам, удалить пару файлов в Корзину.
4. В программе: ⚙ → выключить «Режим проверки» → Почистить.
